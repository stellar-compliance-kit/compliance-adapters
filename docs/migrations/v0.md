# Migrating to v0

This guide covers the upgrade path to the `0.1.0` release, the first (and so far only) released major version of this package. See the [migrations index](./README.md) for all migration guides and the [CHANGELOG](../../CHANGELOG.md) for the full history of changes.

## Summary of the initial release

`0.1.0` is the initial published version of the package. It ships with the following functionality:

- **SEP-10 authentication** — a challenge builder and verifier for SEP-10 (Stellar Web Authentication), allowing services to issue signed challenges and verify signed challenge responses from clients.
- **Sanctions oracle** — a mock provider implementing the sanctions-oracle interface, useful for local development and testing of sanctions checks.
- **Horizon listener** — event polling against Horizon, allowing consumers to subscribe to and process ledger/transaction events.

## Breaking changes

None. There are no prior releases, so there is no earlier API to migrate from. If you are adopting the package for the first time, simply install `0.1.0` and follow the usage examples in the project documentation.

## Migration steps

1. Install the package at version `0.1.0` (or later within the `0.x` line).
2. Review the [CHANGELOG](../../CHANGELOG.md) for the list of features included in this release.
3. Wire up the components you need (SEP-10 challenge builder/verifier, sanctions-oracle mock provider, horizon listener) following the project documentation.

## Code examples

There are no before/after examples for this release since it is the initial version. Refer to the project documentation and the [CHANGELOG](../../CHANGELOG.md) for usage guidance.
